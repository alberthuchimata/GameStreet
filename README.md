# Street Gay Fighter

Projeto estático pronto para Vercel. Importe esta pasta como projeto no Vercel com Framework Preset **Other** e Root Directory na pasta que contém `index.html`. Deixe Build Command vazio; não há dependências nem etapa de build.

Estrutura: `index.html`, arquivos CSS/JS na raiz, imagens em `assets/`. Mantenha os nomes sem sufixos `(1)` ou `(2)` e preserve maiúsculas/minúsculas dos caminhos.

Para testar localmente: `python -m http.server 8000` nesta pasta e abra `http://localhost:8000`.
